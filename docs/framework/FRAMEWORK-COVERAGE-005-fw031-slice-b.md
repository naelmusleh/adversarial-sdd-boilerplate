# FRAMEWORK-COVERAGE-005 — FW-TASK-031 slice B GitHub Actions profile journeys and surfaces

## Scope and evidence boundary

This G-COVERAGE matrix covers only FR-FW-041–043 under DECISION-038: a proposed optional GitHub Actions workflow/job-level profile. FRAMEWORK-FEASIBILITY-014 is bounded feasibility evidence, not profile adoption. Its current findings constrain each journey: private repository job collection and timeout configuration are conditional; workload/process-tree termination remains blocked pending a separately authorized synthetic workload test; tool calls, agent-internal retries, nested-agent accounting, CPU/memory, and spend remain unknown unless a future source directly measures them with scope and provenance.

The matrix defines requirements and failure/recovery behavior, not an implementation or end-user interface. It does not change workflows or permissions, select a host/profile for use, choose thresholds or a meter, run or cancel a workload, collect application data, authorize implementation, or make enforcement, cost, or termination claims. `run_attempt` means only an Actions rerun. Workflow/head/executed revisions remain distinct fields when their provenance differs.

## State axes and invariants

| Axis | Required states / invariant | Journey coverage |
| --- | --- | --- |
| Record identity | Required repository/workflow/run/run-attempt/job/source-revision tuple; missing or conflicting member is `unknown`/invalid and cannot be completed across records. | J-031B-01, J-031B-06 |
| Revision semantics | Workflow revision, event/head revision, and executed revision are separately labeled when available; no substitution without an explicit source relation. | J-031B-01, J-031B-06 |
| Timing | Source field, scope, and interval are explicit; absent or incompatible timestamps remain unknown; overlapping jobs are not blindly summed. | J-031B-01, J-031B-02 |
| Timeout | Configured value, observed timeout event, and job outcome are distinct; configuration alone proves no enforcement. | J-031B-03 |
| Cancellation | Request, host terminal conclusion, and exact workload/process-tree termination observation are distinct; no termination claim without the last. | J-031B-04 |
| Measurement availability | Each metric is `measured` with provenance or `unknown`/`unavailable`; no proxy-derived numeric value. | J-031B-05, J-031B-06 |
| Access/evidence freshness | Authorized, complete, exact-revision evidence is reviewable; denied, degraded, stale, or partial collection remains non-pass/unknown. | J-031B-06 |

Cross-surface invariant: repository contracts define what evidence means; an Actions source supplies only its reported run/job data; the evidence record preserves source identity and uncertainty; review confirms scope and limitations. No surface may transform a request into an outcome, a host job result into workload termination, or missing measurements into zeros.
